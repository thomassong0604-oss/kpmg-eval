## Slide 4: Routing (1:15)

Turning to routing, I would like to correct two points from last week's presentation. First, the bars represent coverage, not accuracy. Coverage means that the tools a question requires were called. It does not mean that the final answer was correct. Coverage of 95 percent therefore does not mean 95 correct answers out of 100. Second, the 95 percent figure belongs to calling every tool on every question. The keyword router alone covers 83 percent. You also asked how unneeded calls are measured. An unneeded call is a call to a tool that the question did not require. A question about total revenue requires only the financial data tool, so if all three tools are called, two of those calls are unneeded. The table shows the resulting trade-off. Calling every tool achieves 95 percent coverage at three calls per question, about two of them unneeded. The keyword router achieves 83 percent with approximately one call. Coverage should therefore always be read alongside cost.

Text search alone calls the wrong tool. The keyword router recognizes the word 'total' and calls the financial data tool, so the question is covered with no unneeded calls. 'What does revenue allocated to remaining performance obligations include?' is a text question, but the word 'revenue' directs the keyword router to financial data, and the question is missed. The Agents' orchestrator performs the actual routing, and it can be scored on the same questions with a single command.
